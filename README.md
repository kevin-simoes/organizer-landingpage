## 📖 Resumo do Projeto

Esse projeto consiste no desenvolvimento da Landing Page do **Organizer**, uma proposta de aplicativo nativo da marca de smartphones JOVI, voltado à organização de anotações e imagens para estudantes e professores.

A página foi criada com o objetivo de apresentar ao público-alvo as principais funcionalidades e a proposta do aplicativo, utilizando uma interface simples, moderna e objetiva para demonstrar a experiência planejada para o projeto.

### Formulário

Voltado para uma simulação de pré-registro, o formulário possui validações responsáveis por verificar se os campos foram preenchidos corretamente.  

Após a validação, um prompt é exibido solicitando a autorização do usuário para compartilhar as respostas fornecidas. Caso permitido, as informações são exibidas no console da página e armazenadas localmente durante a execução.
